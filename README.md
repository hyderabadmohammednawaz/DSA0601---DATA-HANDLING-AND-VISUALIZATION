## 💡 Why Data Visualization?

Raw data can contain thousands of values, but a well-designed visualization can reveal a pattern in seconds.

For example:

```text
Raw Data
   ↓
Data Handling
   ↓
Exploratory Analysis
   ↓
Visualization
   ↓
Patterns & Relationships
   ↓
Better Understanding
```

This course explores how the **choice of chart, color, scale, coordinate system, and visual design** can change the way information is understood.

---

# 🎯 Course Objectives

The course aims to develop the ability to:

1. Design and create data visualizations.
2. Conduct exploratory data analysis using visualization.
3. Craft visual presentations of data for effective communication.
4. Understand perception and cognition to evaluate visualization design alternatives.
5. Design and evaluate color palettes for visualization based on principles of perception.

---

# 🎓 Course Outcomes

After completing this course, I aim to be able to:

* Understand fundamental concepts, principles, and techniques of data visualization.
* Apply appropriate visualization methods to represent distributions, proportions, and relationships.
* Analyze patterns, trends, and associations using visualization techniques.
* Evaluate visualization designs using perception, cognition, and effectiveness principles.
* Explain the principles of proportions.
* Create effective and interactive visualizations by integrating data wrangling and advanced visualization tools.

# 🔬 Visualization Learning Journey

One of the important ideas I am focusing on in this course is:

```text
DATA
 ↓
UNDERSTAND
 ↓
CLEAN & HANDLE
 ↓
EXPLORE
 ↓
CHOOSE VISUALIZATION
 ↓
DESIGN
 ↓
INTERPRET
 ↓
COMMUNICATE
```

A chart is not automatically a good visualization just because it looks attractive.

The important question is:

> **Does the visualization help the viewer understand the data correctly?**

This repository will therefore focus on both **technical implementation and visualization design principles**.

---

# 🎨 Visualization Checklist

Before considering a visualization complete, I will check:

* [ ] Is the visualization appropriate for the data?
* [ ] Are the axes clear?
* [ ] Are labels understandable?
* [ ] Is the color palette meaningful?
* [ ] Is unnecessary information removed?
* [ ] Is the visualization accessible?
* [ ] Does it avoid misleading the viewer?
* [ ] Does it communicate the intended pattern clearly?
